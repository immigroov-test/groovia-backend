# Session category review

All 182 sessions belonging to migrated (old) mentors, with the category each is filed under **today on
staging**. These were assigned automatically from the session title; the old system had no categories
at all, so every one of these is a machine guess that has never been checked by a person.

Category drives two things a customer sees: the filters on the Mentors page, and the label on each
session. A wrong one means the session is invisible to someone filtering for it.

**How to review:** scan the `CATEGORY` column. Where you disagree, change it to one of:

`Visa & Immigration`, `Jobs & Careers`, `Housing & Relocation`, `Education & Studies`,
`Finance & Taxes`, `Culture & Daily Life`, `Business & Startup`, `General Guidance`

Hand the file back and I apply exactly what it says, to staging and to production.
